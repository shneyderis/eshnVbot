# Voice → text bot (WhatsApp → Telegram → OpenAI)

Личный Telegram-бот: пересылаешь ему голосовое (из WhatsApp или любое другое) или картинку с текстом, получаешь текст. Язык определяется автоматически (русский, украинский, английский и др.).

Хостинг: Vercel (serverless, без сервера). Распознавание: OpenAI `gpt-4o-transcribe`.

## Как пользоваться (iPhone)

1. В WhatsApp зажать голосовое → **Переслать** → внизу слева иконка **Поделиться** → **Telegram** → выбрать чат с ботом.
2. Через несколько секунд бот отвечает текстом (и переводом, если задан `TRANSLATE_TO`).
   Картинки (фото, скриншоты, сканы) пересылаются так же: бот читает с них текст и дальше работает как с голосовым.
   Видео: распознаётся речь со звуковой дорожки. Надписи на экране в видео не читаются.
3. Разовый перевод на другой язык: ответить на сообщение бота командой `/tr en` (любой язык).
4. Разовый пересказ: ответить на сообщение бота командой `/sum`.
5. `/help` — напоминание команд. Они же в меню по кнопке «/» в Telegram.

## Установка (один раз, ~10 минут)

1. **Бот в Telegram.** Написать [@BotFather](https://t.me/BotFather) → `/newbot` → сохранить токен.
2. **Ключ OpenAI.** https://platform.openai.com/api-keys → создать ключ. Нужен положительный баланс (минута речи ≈ $0.006).
3. **Деплой на Vercel.** Новый проект из этого репозитория. В Settings → Environment Variables добавить:

   | Переменная | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от BotFather |
   | `OPENAI_API_KEY` | ключ OpenAI |
   | `TELEGRAM_WEBHOOK_SECRET` | любая случайная строка |
   | `ADMIN_USER_IDS` | твой Telegram id (см. шаг 5) |

   Необязательно:
   - `ALLOWED_USER_IDS=111,222` — статический список id, которым можно всегда, без `/join`.
   - `TRANSLATE_TO=ru` — после текста присылать перевод на этот язык (если речь уже на нём, перевода не будет).
   - `SUMMARY=1` — после текста присылать короткий пересказ без воды. Только для сообщений длиннее 300 символов (порог: `SUMMARY_MIN_CHARS`). Пересказ на языке `TRANSLATE_TO`, если задан, иначе на языке речи.
   - `TRANSCRIBE_LANGUAGE=ru` — подсказка языка речи, по умолчанию автоопределение.
   - `TRANSCRIBE_MODEL=whisper-1`, `TRANSLATE_MODEL=gpt-4o-mini` — смена моделей.

4. **Подключить webhook** (подставить свои значения):

   ```bash
   curl "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
     -d "url=https://<проект>.vercel.app/api/telegram" \
     -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>" \
     -d "drop_pending_updates=true"
   ```

   Проверка: `curl "https://api.telegram.org/bot<TOKEN>/getWebhookInfo"`.

5. **Узнать свой id.** Написать боту `/start` — он ответит и покажет id. Вписать его в `ADMIN_USER_IDS` и сделать Redeploy. Пока не задана ни одна из `ADMIN_USER_IDS`, `ALLOWED_USER_IDS` и хранилище, ботом может пользоваться кто угодно за твой счёт.

## Доступ для других людей (кодовое слово)

Люди пишут боту `/join слово`, бот их запоминает. Нужно хранилище, потому что serverless-функция сама ничего не помнит.

1. Vercel → проект → вкладка **Storage** → **Create Database** → **Upstash** → Redis → бесплатный план → Create → Connect to project. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами.
2. В Environment Variables добавить `JOIN_PASSWORD` = кодовое слово, `ADMIN_USER_IDS` = твой id. Redeploy.
3. Дать человеку слово. Он пишет боту `/join слово` и может пользоваться.

Команды админа (только для id из `ADMIN_USER_IDS`):

| Команда | Действие |
|---|---|
| `/users` | список зарегистрированных: id, имя, дата |
| `/ban <id>` | удалить и заблокировать (повторный `/join` не сработает) |
| `/unban <id>` | снять блокировку, человеку нужно снова `/join` |

Кто имеет доступ: админы, id из `ALLOWED_USER_IDS`, и те, кто прошёл `/join` и не забанен. Чтобы отрезать всех разом, поменяй `JOIN_PASSWORD` (уже вошедшие остаются) или очисти базу в Upstash.

## Звонки: бот звонит за тебя (`/call`)

Пишешь боту номер и задание, он показывает план, после кнопки «Звонить» голосовой ИИ-агент ElevenLabs звонит через твой SIP-транк и присылает итог с расшифровкой.

```
/call +34931234567 запиши меня к терапевту на следующую неделю, утром
```

**Голосом:** наговори голосовое, которое начинается со слова «позвони» («набери», «подзвони», «call»): «Позвони в клинику по номеру такому-то и запиши меня к терапевту на следующую неделю». Бот покажет, что расслышал, и сразу план с кнопкой. Срабатывает только на твои собственные голосовые; пересланные чужие просто расшифровываются, как раньше. На любой другой текст с заданием можно ответить командой `/call`.

Только для админа (`ADMIN_USER_IDS`): звонки платные и идут с твоего номера.

**Без номера, по названию:**

```
/call позвони в ресторан Disfrutar в Барселоне, стол на двоих в пятницу в 21:00
```

Бот берёт номер из своей базы, а если там нет — ищет в интернете и показывает в плане найденный номер, адрес и источник. Проверь его перед кнопкой «Звонить»: поиск может ошибиться. После подтверждения номер запоминается под этим названием. `/contacts` — что бот запомнил, `/forget <название>` — забыть номер.

Что бот делает сам: определяет язык звонка, ждёт «алло» и первой фразой говорит, что он ИИ-ассистент и звонит от твоего имени, не выдумывает данные, которых нет в задании (отвечает, что уточнит), не называет и не принимает данные карт.

### Настройка (один раз)

1. **Хранилище.** Нужен Redis из раздела «Доступ для других людей» (шаг 1). Без него `/call` не работает.
2. **ElevenLabs → Agents → новый агент.**
   - **Agent settings → Security** → включить overrides: **System prompt** и **Agent language**.
   - Добавить языки, на которых будут звонки (японский, испанский и т. д.), и выбрать голос.
   - **First message** оставить пустым для каждого языка: на исходящем звонке первым говорит тот, кто снял трубку. Вступление бот берёт из задания. (Override первой фразы на бесплатном тарифе недоступен, поэтому он не используется.)
   - **Tools → System tools** → включить **End conversation** (иначе агент не сможет сам положить трубку) и **Voicemail detection**.
   - Нажать **Publish**.
3. **ElevenLabs → Telephony → Import number.** У ElevenLabs своих номеров нет, номер импортируется от оператора:
   - **From SIP Trunk** — данные провайдера: адрес, транспорт (TCP или TLS), логин и пароль, номер в формате `+…`.
   - **From Twilio** — номер, купленный в Twilio; тогда в Vercel добавить `ELEVENLABS_TELEPHONY=twilio`.

   Привязать номер к агенту.
4. **ElevenLabs → Agents → Settings → Post-call webhook.** URL `https://<проект>.vercel.app/api/call-result`, события: transcript и call initiation failure. Сохранить секрет.
5. **Vercel → Environment Variables**, затем Redeploy:

   | Переменная | Значение |
   |---|---|
   | `ELEVENLABS_API_KEY` | ключ API ElevenLabs |
   | `ELEVENLABS_AGENT_ID` | id агента |
   | `ELEVENLABS_PHONE_NUMBER_ID` | id импортированного номера |
   | `ELEVENLABS_WEBHOOK_SECRET` | секрет webhook из шага 4 |
   | `CALL_ON_BEHALF_OF` | от чьего имени звонит бот, например `Eugene` |

   Необязательно:
   - `CALL_CALLBACK_NUMBER=+34…` — номер, который бот назовёт, если попросят перезвонить. Без него отвечает, что ты перезвонишь сам.
   - `CALL_TIMEZONE=Europe/Madrid` — часовой пояс для «завтра», «в пятницу» в задании.
   - `CALL_PLAN_MODEL` — модель OpenAI, которая разбирает задание и пишет итог. По умолчанию та же, что `TRANSLATE_MODEL`.
   - `CALL_SEARCH_MODEL` — модель OpenAI, которая ищет номер в интернете (нужна поддержка инструмента web search). По умолчанию та же, что `CALL_PLAN_MODEL`.
   - `ELEVENLABS_TELEPHONY=twilio` — если номер импортирован из Twilio, а не из SIP-транка.

Проверка: `/call` на свой мобильный с простым заданием.

## Ограничения

- Файл до 20 МБ (лимит Telegram Bot API). Голосовое WhatsApp длиной в час ≈ 10 МБ.
- Один запрос ≤ 60 секунд (лимит Vercel). Хватает на голосовые до ~20–30 минут.
- Звонки: план ждёт подтверждения 15 минут. Телефонные меню («нажмите 1») и автоответчики бот не проходит, кладёт трубку.
